INSTRUCTIONS:
Must have visual studio 2022 or higher installed to run SLN File

Rogue of the Dark Ages is a turn-based medieval strategy game utilizing C# and WinForms

First use the drop down menu in the top right to choose on of 5 classes
The game will then begin
Refer to battle log for class descriptions when chosen
Total of 6 levels + a boss battle
Player has choice of 3 upgrades after every level
Good luck!
